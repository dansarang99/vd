# 🎨 PPT Style Cloner Pro (`vd26_ppt_clone_skill`)

> **프리미엄 프레젠테이션의 스타일 DNA를 역공학하여 4대 마스터 자산 추출, 1차 100% 무결 복제, 1:1 정밀 검증 및 2차 완성형 고도화 슬라이드를 생성하는 에이전트 스킬 패키지**

---

## 🌟 Key Features
- **4대 마스터 자산 자동 추출**:
  - `BUSINESS_DNA.md`: 비즈니스 도메인, 가치 제안, 3대 증명 지표
  - `DESIGN.md`: 디자인 8요소(그리드, 컬러, 타이포그래피, 코너, 보더, 섀도, 서피스, 아이콘)
  - `STYLE.md`: 여백 비율(45%+), 시각적 위계 문법, 엄격한 Do's & Don'ts
  - `TEMPLATE.md`: 슬라이드 컨테이너 좌표계 및 뼈대 구조
- **제1차 100% 무결 복제 (Gen-1 Exact Replica)**:
  - 원문 텍스트, 띄어쓰기, 숫자 단위를 토씨 하나 틀리지 않고 100% 동일하게 파이썬 코드로 복제
- **1:1 정밀 비교 검증 (1:1 QA Gap Analysis)**:
  - 부족한 부분(Under-engineered), 과도한 부분(Over-engineered), 추가 개선 요소를 도출
- **제2차 고도화 완성 슬라이드 (Gen-2 Enhanced Master)**:
  - Hero 카드 돌출 강조, 마이크로 기술 태그, WCAG 명도 대비비 최적화를 반영한 보드룸 레벨 프레젠테이션

---

## 📂 Directory Structure
```
vd26_ppt_clone_skill만들기/
├── README.md                 # 프로젝트 매뉴얼
├── SKILL.md                  # 에이전트 마스터 스킬 명세서
├── templates/
│   ├── BUSINESS_DNA.md       # 비즈니스 내러티브 템플릿
│   ├── DESIGN.md             # 디자인 8요소 마스터 템플릿
│   ├── STYLE.md              # 비주얼 스타일 가이드 템플릿
│   └── TEMPLATE.md           # 레이아웃 뼈대 템플릿
└── scripts/
    ├── replicate_v1_exact.py     # 1차 100% 무결 복제 스크립트
    └── replicate_v2_enhanced.py  # 2차 완성형 고도화 복제 스크립트
```
