# 🎬 AI 비디오 제작 5단계 파이프라인 & 5대 마스터 대본 생성기
> **Google Flow & Vids, Vrew, CapCut, Filmora, Runway 완벽 대응 마스터 패키지**

본 저장소는 특정 주제와 기획 아이디어만으로 **(1)캐릭터 생성 → (2)캐릭터 시트 → (3)기승전결 시놉시스 → (4)장면 연출 확장 → (5)용도별 5대 마스터 대본**을 원스톱으로 산출할 수 있도록 설계된 교육 및 실무용 AI 영상 기획 파이프라인입니다.

---

## 🌟 왜 5대 대본이 필요한가요?

AI 영상 제작 시 가장 큰 병목은 **"이미지 툴, 영상 툴, TTS 툴, 자막 툴마다 요구하는 서식과 프롬프트가 다르다"**는 점입니다.  
본 파이프라인을 사용하면 기획 단계에서 한 번에 5대 트랙 대본이 생성되어 각각의 제작 도구에 복사/붙여넣기만 하면 영상이 완성됩니다.

| 트랙 | 대상 도구 | 주요 내용 |
| :--- | :--- | :--- |
| **🖼️ Track 1. 이미지 생성용** | Midjourney, Google Flow, Imagen 3, Flux | 고정 Visual DNA 앵커, 16:9 비율 최적화 영문 프롬프트 |
| **🎥 Track 2. 동영상 생성용** | Runway Gen-3, Luma Dream Machine, Kling, Veo 2 | 카메라 무브먼트(Pan, Tilt, Zoom, Dolly) 및 모션 속도 지시문 |
| **🎙️ Track 3. 나레이션용** | Google Vids TTS, Vrew, Typecast, ElevenLabs | 감정선 및 호흡 쉼표가 반영된 2~3문장 한국어 구연동화 대본 |
| **📝 Track 4. 자막 생성용** | CapCut, Vrew 화면 하단 자막 | 1회 1~2줄, 줄당 20자 내외의 시인성 높은 자막 텍스트 |
| **🔊 Track 5. 사운드 디자인** | Suno, Udio, CapCut 오디오 라이브러리 | 캐릭터 현장 돌발 대사, 필수 효과음(SFX), 장면별 BGM 무드 |

## 🚀 수강생 빠른 실습 가이드 (How to Use)

### 1단계: AI 에이전트(Gemini, ChatGPT, Claude 등)에게 요청하기
본 저장소의 `./templates/script_format_template.md`를 참고하여 아래와 같이 프롬프트를 입력합니다:

```text
[주제]: 토끼와 거북이의 달리기 시합
[기획 아이디어]: 최첨단 네온 사이버펑크 도시에서 펼쳐지는 호버보드 토끼와 외골격 로봇 거북이의 레이스
[목표 분량]: 6장면 (약 60초 쇼츠/릴스)
[스타일]: 3D 픽사 애니메이션 + 사이버펑크

위 내용을 바탕으로 `ai-video-pipeline` 5단계 프로토콜에 따라:
1. 캐릭터 프로필 및 Visual DNA
2. 캐릭터 시트 (턴어라운드 및 주요 표정)
3. 기승전결 N장면 줄거리
4. 각 장면별 연출 시나리오
5. 장면별 5대 마스터 대본 (이미지/동영상/TTS/자막/효과음)
을 표와 코드블록 형태로 생성해줘.
```

## 📁 100% 상대 경로 기반 디렉토리 구조

본 저장소의 모든 파일은 절대 경로 없이 **100% 상대 경로(`relative path`)**로 구성되어 있어, 어떤 PC나 디렉토리에 다운로드받아도 즉시 정상 작동합니다.

```text
.
├── SKILL.md                              # [핵심] AI 에이전트 시스템 스킬 정의서
├── README.md                             # [안내서] 저장소 메인 사용 설명서
├── workflows/                            # 단계별 실무 가이드라인
│   ├── 01_pipeline_workflow.md           # 1~5단계 시나리오 및 5대 대본 작성법
│   └── 02_google_vids_guide.md           # 6~10단계 구글 Vids 실전 영상 조립/편집법
├── templates/                            # 프롬프트 및 대본 템플릿
│   ├── master_prompt_templates.md        # 생성 툴별 프롬프트 작성 공식
│   └── script_format_template.md         # 수강생 실습용 빈 마크다운 템플릿
├── examples/                             # 실전 검증 완성본
│   └── rabbit_and_turtle_master.md       # "토끼와 거북이" 8장면 풀 시나리오 및 5대 대본
├── scripts/                              # 자동화 보조 도구
│   └── export_to_srt.py                  # 대본에서 자막(.srt) 파일 자동 추출 스크립트
├── prompt/                               # 실습용 프롬프트 저장 폴더
└── result/                               # 결과물 (SRT 자막, 생성 파일 등) 저장 폴더
```

## 🛠️ 자막 자동 추출 스크립트 실행법

생성된 마크다운 대본에서 자막(Track 4)만을 추출하여 CapCut, Premiere, Vrew에서 즉시 불러올 수 있는 `.srt` 자막 파일로 내보낼 수 있습니다.

```bash
# 기본 예시(토끼와 거북이) 자막 변환 실행 (상대 경로)
python scripts/export_to_srt.py

# 직접 작성한 마크다운 파일로 변환할 경우
python scripts/export_to_srt.py [대본파일경로.md] [출력파일경로.srt]
```
> 변환된 자막 파일은 `./result/subtitles.srt` 에 자동 생성됩니다.

## 🎬 툴별 실전 연동 팁

1. **Google Flow**:
   - `Track 1`의 영문 프롬프트로 고품질 배경 이미지를 생성합니다.
   - 캐릭터의 고정 앵커 키워드(`Visual DNA`)를 첫머리에 유지하여 장면 간 인물 일관성을 유지합니다.
2. **Runway Gen-3 / Luma**:
   - `Track 1`에서 생성된 이미지를 첫 프레임(First Frame)으로 넣고, `Track 2`의 모션 프롬프트를 입력하여 자연스러운 4초 비디오 클립을 생성합니다.
3. **Google Vids**:
   - `Track 2`로 만든 비디오 클립들을 타임라인에 배치합니다.
   - `[Script]` 메뉴에 `Track 3` 나레이션을 넣고 '친근한 구연동화' 목소리로 TTS를 생성합니다.
   - `Track 4` 자막을 하단에 배치하고, `Track 5`의 SFX(바람, 환호 등)와 배경음악을 합성합니다.
4. **Vrew**:
   - `[텍스트로 비디오 만들기]`에 `Track 3` 나레이션을 붙여넣으면 목소리와 자막이 한 번에 자동 생성됩니다.
