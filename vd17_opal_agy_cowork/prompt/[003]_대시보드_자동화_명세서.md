## 1. 실시간 대시보드 (Executive Glassmorphism Dashboard)
* **결과물**: `result/latest_report.html` (단일 파일 독립형 완결)
* **디자인 테마**:
  - 다크/모던 럭셔리 글래스모피즘 (블러 효과, 섬세한 보더, 그라데이션)
  - 상단 헤더: "완주로컬푸드 오늘의 판매현황 실시간 모니터링"
  - 실시간 상태 뱃지: `LIVE` (마지막 갱신 시각 및 다음 갱신 카운트다운 타이머)
  - 4대 핵심 KPI 카드: 총 매출액, 총 판매량, 1위 매장 점유율, 1위 인기 품목
  - 반응형 2x2 그리드: 고화질 분석 차트 4종 및 클릭 확대(Lightbox) 모달
  - 실시간 세부 데이터 테이블: 검색, 페이징, 정렬 지원
  - 경영진 브리핑 인사이트 요약 (Executive Insights)

## 2. 1시간 주기 자동화 스케줄러 (Scheduler Daemon)
* **모듈**: `src/scheduler.py`
* **주기 설정**:
  - 기본 운영 모드: 1시간(3600초) 간격
  - 테스트/강의 모드: 10초 또는 수동 1회 즉시 실행
* **주기별 수행 작업**:
  1. `opal_connector.py` 호출: 최신 판매현황 API 쿼리 및 CSV 수신
  2. `eda_engine.py` 호출: 데이터 정제 및 통계 지표 산출
  3. `visualizer.py` 호출: 4대 차트 최신화 저장
  4. `dashboard_generator.py` 호출: `result/latest_report.html` 및 버전별 아카이브(`result/history/report_YYYYMMDD_HH.html`) 생성
  5. C-Level 마크다운 브리핑 문서 `result/executive_summary.md` 갱신
  6. 완료 로그 기록 및 다음 사이클 대기
