# BJ Jang Business & Government Grant Proposal Deck - Design Specification

> 비제이짱(BJ Jang) 비즈니스 제안서 및 정부지원사업(예창패, 초창패, R&D 등) 발표 전용 템플릿입니다.
> 심사위원의 시선을 사로잡는 신뢰감 있는 딥 네이비 톤과 명확한 간트차트, 추진 체계도, 정량적 기대효과 구조를 갖추고 있습니다.

## I. Template Overview

| Property | Description |
| --- | --- |
| **Template Name** | bjjang_proposal |
| **Display Name** | 비제이짱 비즈니스 및 정부지원사업 제안서 템플릿 |
| **Use Cases** | 정부지원사업 발표평가, 대기업 B2B 제안서, 신규 사업 추진 기획서 |
| **Design Tone** | 논리적, 신뢰성, 정량 지표 강조, 컨설팅 보고서 스타일 |
| **Theme Mode** | 고대비 비즈니스 화이트 + 딥 네이비 구조색(`#0F172A`) + 로열 블루 액센트 |

## II. Canvas Specification

| Property | Value |
| --- | --- |
| **Format** | Standard 16:9 (`ppt169`) |
| **Dimensions** | 1280 × 720 px |
| **Margins** | 좌우 60px, 상단 52px, 하단 60px |

## III. Key Slide Roster

1. `01_cover.svg`: 제안 과제명, 주관 기관/기업명, 제출일, 총괄 책임자
2. `02_background_problem.svg`: 시장의 미충족 수요(Unmet Needs) 및 사업 추진 필요성
3. `03_gantt_timeline.svg`: 12개월/4분기 마일스톤 및 세부 추진 일정 간트차트
4. `04_governance_org.svg`: 총괄/기획/개발/운영 전담 추진 조직도 및 산학연 협력 체계
5. `05_expected_roi.svg`: 정량적 성과 목표(매출, 고용창출, 비용절감) 및 파급 효과
