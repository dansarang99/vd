# BJ Jang Signature Brand Specification

> 비제이짱(BJ Jang) 시그니처 프레젠테이션 브랜드 아이덴티티 규격서입니다.
> 강의 교안, 비즈니스 제안서, IR 피치덱, 테크 아키텍처 발표에 최적화된 고시인성/고신뢰도 팔레트입니다.

## I. Brand Overview

| Property | Value |
|---|---|
| Brand Name | BJ Jang (비제이짱) |
| Use Cases | AI 강의, 실무 워크숍, 정부지원사업 제안서, 스타트업 IR 피치덱, 테크 아키텍처 발표 |
| Tone | Authoritative, clear, energetic, educational — 신뢰감 있고 직관적인 한국어 강의/비즈니스 톤 |

## IV. Voice & Presentation Principles

1. **1슬라이드 1메시지 (Takeaway Focus)**:
   - 각 슬라이드 상단에는 해당 장표에서 청중이 가져가야 할 1줄 핵심 결론(Takeaway)을 명시합니다.
2. **청중 중심의 구어체 스피커 노트 (Speaker Notes)**:
   - 슬라이드 하단 메모란에 발표자가 청중을 보며 말할 수 있는 **1분 발표 대본**을 기본 탑재합니다.
3. **고대비 가독성**:
   - 프로젝터나 모니터 화면 어디서든 흐릿하지 않도록 배경 대비 본문 텍스트 명암비를 7:1 이상 유지합니다.
4. **절제된 액센트 사용**:
   - 슬라이드 1장당 시그니처 블루(`#2563EB`) 강조 영역은 최대 2~3개 이하로 제한하여 피로도를 줄입니다.
