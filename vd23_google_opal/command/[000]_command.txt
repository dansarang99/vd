[배치 파일 목록]
1. 01_환경설치_원클릭.bat
   - 필요한 파이썬 라이브러리(streamlit, rich, pyperclip 등)를 자동 설치합니다.

2. 02_Opal프롬프트생성기_실행.bat
   - CLI 터미널 환경에서 5대 프리셋 또는 사용자 맞춤형 프롬프트를 생성하고
     클립보드에 자동 복사합니다.

3. 03_Streamlit_웹앱_실행.bat
   - 강의 프로젝터 시연에 최적화된 로컬 웹 대시보드를 구동합니다.

4. 04_스킬전역등록_원클릭.bat
   - Antigravity 및 Gemini CLI 전역 스킬 폴더에 vd23 스킬을 즉시 등록합니다.

[수동 실행 명령어]
- 가상환경 설치:
  pip install -r ../requirements.txt

- CLI 실행:
  python ../src/cli.py

- Streamlit 웹앱 실행:
  streamlit run ../src/app_streamlit.py
